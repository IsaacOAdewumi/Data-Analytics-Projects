# Quick Tech Tip | Data Analytics & Statistical Insights

This folder contains practical, review-ready tips for analysts, researchers, and decision-makers. Each post focuses on one useful technique or concept and is saved as a separate Markdown file.

## Topic categories

Tips rotate across Excel, SQL and databases, Power BI, Python, R, statistics, research and dissertation analysis, data visualisation, machine learning, and business analytics.

## Publishing workflow

For each daily draft:

1. Check `content-log.md` and previous posts to avoid repetition.
2. Choose a focused topic and verify any formulas, code, and statistical interpretation.
3. Save the post as `YYYY-MM-DD-quick-tech-tip.md` and add its date, topic, category, and summary to the content log.
4. Review and publish the draft separately. Saving a post here does not publish it to a social platform.

The Quick Tech Tips automation is scheduled for 8:00 a.m. Africa/Lagos time. It prepares drafts for review; it does not publish them.

## Contributing

Suggest a practical, specific topic from one of the categories above. Keep examples clearly illustrative, avoid unsupported claims, and follow the post structure used in the existing tips. Update the content log whenever a new draft is added.
